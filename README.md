Concept de site pentru o clinică stomatologică, cu programare online în 60 de secunde.

## Ce conține

- Programare rapidă pe serviciu și dată
- Pagini pentru medici, servicii, prețuri, blog și despre noi
- Banner de cookie-uri și buton fix de WhatsApp
- Versiune în română și engleză

## Stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · React Router · Framer Motion

## Rulare locală

```sh
npm install
npm run dev
```
